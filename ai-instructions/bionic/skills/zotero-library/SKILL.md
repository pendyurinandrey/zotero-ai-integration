# Поиск и цитирование в Zotero

Запрос пользователя уже разрешает проверку Ollama и поиск в режиме чтения. Если вопрос приложен как изображение, сначала прочитай текст задания и все варианты, сохраняя их буквы или номера. Если часть текста неразборчива, уточни только её. Затем сразу начни проверку Ollama и поиск. Если Ollama уже проверен в этой сессии, начни с команды поиска. Согласие на запуск проверки и поиска отдельно не запрашивай.

Вызывай встроенный инструмент Bionic `shell_command`. Передавай три поля: `command` (вся команда), `workdir` (абсолютный путь к текущему проекту Bionic) и `timeout_ms` (число в миллисекундах). Для поиска и проверки индекса используй `60000`. При ошибке «timeout_ms Required» повтори вызов с этим полем.

Для любого поиска по этому скилу вызывай `search-passages.sh` через `shell_command`. Это правило действует и после чтения приложенного изображения. Не вызывай инструменты MCP Zotero напрямую, в том числе как запасной способ. Если доступ к `shell_command` отсутствует, попроси включить **Allow coding** в проекте.

1. Перед первым поиском проверь Ollama. Пример аргументов `shell_command`. Подставь путь к текущему проекту Bionic.

   ```json
   {
     "command": "curl -fsS --max-time 5 http://127.0.0.1:11434/api/version",
     "workdir": "/путь/к/текущему-проекту",
     "timeout_ms": 10000
   }
   ```

   Если сам `curl` завершился ошибкой соединения, попроси запустить `brew services start ollama` и останови поиск. Приложение Zotero может быть закрыто.
2. Возьми коллекцию или `Item Key` из запроса или из ранее выбранной области. Если область не задана, ищи по всей библиотеке. Подбери три разных набора ключевых слов по теме. Сформулируй из каждого набора один короткий вопрос или связную фразу для смыслового поиска. Передавай каждую фразу отдельным аргументом в отдельном вызове `shell_command`. Операторы `OR` и `AND` в запросе не используй. Выполни все три поиска, даже если первый уже дал подходящий фрагмент.

   Для теста формулируй запросы по содержанию вопроса и различиям между вариантами. В каждом вызове передавай указанную пользователем коллекцию через `--collection`. Собери фрагменты для проверки всех вариантов, прежде чем выбирать ответы.

   Пример для вопроса об этике советов психолога в коллекции «ПЭП». Каждая строка — отдельная команда.

   ```sh
   "$HOME/.local/share/zotero-ai-integration/scripts/search-passages.sh" --collection "ПЭП" --limit 6 --per-item 1 -- "Какие этические нормы регулируют советы психолога клиенту?"
   "$HOME/.local/share/zotero-ai-integration/scripts/search-passages.sh" --collection "ПЭП" --limit 6 --per-item 1 -- "Как профессиональные границы психолога связаны с автономией клиента?"
   "$HOME/.local/share/zotero-ai-integration/scripts/search-passages.sh" --collection "ПЭП" --limit 6 --per-item 1 -- "Когда в психологическом консультировании допустимы прямые рекомендации?"
   ```

   Если ссылка ещё не настроена, используй известный абсолютный путь к репозиторию. Путь `./scripts/search-passages.sh` подходит внутри самого репозитория. Если путь к репозиторию неизвестен, попроси его указать или настроить ссылку.

   Сохраняй область во всех вызовах. Без коллекции опусти `--collection`. Для одной записи передай `--item КЛЮЧ`. Если заданы оба ограничения, сохрани оба. Добавляй `--subcollections`, когда пользователь включил подколлекции в область поиска. При поиске нескольких мест из одной записи используй `--per-item 3`.
3. Просмотри результаты всех запросов и объедини повторы по `Item Key`. Используй все существенно разные релевантные источники, если они есть. Если после трёх вызовов подходит только один источник или ни одного, сделай ещё один запрос по другому аспекту темы или на английском. Сохрани заданную область.
4. Ответь по найденному тексту. Для каждой дословной цитаты возьми из того же результата название, `Item Key` и страницу PDF или таймкод начала реплики. Если страницы и таймкода нет, укажи номер фрагмента. Спикера указывай по заголовку реплики или подсказке скрипта. Перевод помечай отдельно. Если нашёл только один подходящий источник, скажи об этом.

   Для теста укажи номер вопроса, все подтверждённые правильные варианты и краткое обоснование со ссылками. Если фрагментов недостаточно, пометь вариант как «не удалось проверить по коллекции».

Если скрипт предлагает несколько коллекций, покажи варианты и уточни выбор. При ошибке поиска сообщи о ней. Если выдача пуста, можно проверить покрытие индекса скриптом `check-text-layer.sh` из той же папки скриптов с тем же ограничением по коллекции.

Библиотеку используй в режиме чтения. Обновление индекса выполняется отдельно по запросу пользователя.
