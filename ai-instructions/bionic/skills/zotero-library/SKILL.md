# Поиск и цитирование в Zotero

Вызывай встроенный инструмент Bionic `shell_command`. Передавай три поля: `command` (вся команда), `workdir` (абсолютный путь к текущему проекту Bionic) и `timeout_ms` (число в миллисекундах). Для поиска и проверки индекса используй `60000`. При ошибке «timeout_ms Required» повтори вызов с этим полем.

Если для команды появился ответ MCP `has no tool named`, выполни её через `shell_command` с теми же аргументами. Если инструмента выполнения команд нет, попроси включить **Allow coding** в проекте.

1. Перед первым поиском проверь Ollama. Пример аргументов `shell_command`. Подставь путь к текущему проекту Bionic.

   ```json
   {
     "command": "curl -fsS --max-time 5 http://127.0.0.1:11434/api/version",
     "workdir": "/путь/к/текущему-проекту",
     "timeout_ms": 10000
   }
   ```

   Если сам `curl` завершился ошибкой соединения, попроси запустить `brew services start ollama` и останови поиск. Приложение Zotero может быть закрыто.
2. Возьми коллекцию или `Item Key` из запроса или из ранее выбранной области. Если область не задана, ищи по всей библиотеке. Запускай скрипт по полному пути через постоянную ссылку, как в примере.

   ```sh
   "$HOME/.local/share/zotero-ai-integration/scripts/search-passages.sh" --collection "Психология" --limit 6 --per-item 2 -- "Как описывают рабочую память?"
   ```

   Если ссылка ещё не настроена, используй известный абсолютный путь к репозиторию. Путь `./scripts/search-passages.sh` подходит внутри самого репозитория. Если путь к репозиторию неизвестен, попроси его указать или настроить ссылку.

   Без коллекции опусти `--collection`. Для одной записи передай `--item КЛЮЧ`. Если пользователь назвал и коллекцию, и запись, сохрани оба ограничения. Добавляй `--subcollections`, когда пользователь включил подколлекции в область поиска.
3. Прочитай фрагменты целиком. Ответь по найденному тексту. Для каждой дословной цитаты возьми из того же результата название, `Item Key` и страницу PDF или таймкод начала реплики. Если страницы и таймкода нет, укажи номер фрагмента. Спикера указывай по заголовку реплики или подсказке скрипта. Перевод помечай отдельно.
4. Если первый запрос дал слабую выдачу, переформулируй его один раз в той же области. Если данных мало, скажи, что именно не удалось подтвердить. Если скрипт предлагает несколько коллекций, покажи варианты и уточни выбор. При ошибке поиска сообщи о ней. Если выдача пуста, можно проверить покрытие индекса скриптом `check-text-layer.sh` из той же папки скриптов с тем же ограничением по коллекции.

Библиотеку используй в режиме чтения. Обновление индекса выполняется отдельно по запросу пользователя.
