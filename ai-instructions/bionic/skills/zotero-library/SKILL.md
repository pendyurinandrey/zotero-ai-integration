# Поиск и цитирование в Zotero

Вызывай встроенный инструмент Bionic `shell_command`. В каждом вызове передавай три поля: `command` (вся команда), `workdir` (абсолютный путь к корню репозитория) и `timeout_ms` (число в миллисекундах). Для поиска и проверки индекса используй `60000`. При ошибке «timeout_ms Required» повтори вызов с этим полем. `zotero-library` — имя скила, а `./scripts/search-passages.sh` — путь к файлу.

Если для этой команды появился ответ MCP `has no tool named`, выполни её через встроенный терминал с той же коллекцией и тем же запросом. После завершения используй вывод терминала. Если инструмента выполнения команд нет, попроси открыть проект с **Allow coding** и выбрать корень репозитория.

1. Перед первым поиском проверь Ollama. Пример аргументов `shell_command`. Подставь фактический путь к корню репозитория.

   ```json
   {
     "command": "curl -fsS --max-time 5 http://127.0.0.1:11434/api/version",
     "workdir": "/путь/к/zotero-ai-integration",
     "timeout_ms": 10000
   }
   ```

   Если сам `curl` завершился ошибкой соединения, попроси запустить `brew services start ollama` и останови поиск. Приложение Zotero может быть закрыто.
2. Возьми коллекцию или `Item Key` из запроса или из ранее выбранной области. Если область не задана, ищи по всей библиотеке. Например, для запроса «Где в коллекции Психология обсуждали рабочую память?» выполни

   ```sh
   ./scripts/search-passages.sh --collection "Психология" --limit 6 --per-item 2 -- "Как описывают рабочую память?"
   ```

   Без коллекции опусти `--collection`. Для одной записи передай `--item КЛЮЧ`. Если пользователь назвал и коллекцию, и запись, сохрани оба ограничения. Добавляй `--subcollections`, когда пользователь включил подколлекции в область поиска.
3. Прочитай фрагменты целиком. Ответь по найденному тексту. Для каждой дословной цитаты возьми из того же результата название, `Item Key` и страницу PDF или таймкод начала реплики. Если страницы и таймкода нет, укажи номер фрагмента. Спикера указывай по заголовку реплики или подсказке скрипта. Перевод помечай отдельно.
4. Если первый запрос дал слабую выдачу, переформулируй его один раз в той же области. Если данных мало, скажи, что именно не удалось подтвердить. Если скрипт предлагает несколько коллекций, покажи варианты и уточни выбор. При ошибке поиска сообщи о ней. Если выдача пуста, можно проверить покрытие индекса через `./scripts/check-text-layer.sh` с той же коллекцией.

Библиотеку используй в режиме чтения. Обновление индекса выполняется отдельно по запросу пользователя.
