# Реквизиты и RIS для Zotero

Вызывай встроенный инструмент Bionic `shell_command` с полями `command`, `workdir` (абсолютный путь к корню `zotero-ai-integration`) и числовым `timeout_ms` (начни с `60000`). Если инструмент недоступен, попроси открыть проект с **Allow coding**. Возьми путь к папке из запроса, обычно это `fixed`. Сохраняй JSON и RIS рядом с папкой вложений. Исходные файлы используй только для чтения.

1. Создай заготовку и прочитай подсказки по файлам.

   ```sh
   ./scripts/make-ris.sh extract "<папка>" --skeleton "<родитель>/zotero-import.json"
   ```

   Если JSON уже есть, сохрани внесённые правки. Обрабатывай по одному документу. Для PDF при необходимости дочитай титул, выходные данные или страницу с рекомендуемой ссылкой через `pdftotext -f N -l N "<файл.pdf>" -`.
2. Заполни по одной записи на файл, сохраняя значение `file` из заготовки. Укажи тип (`book`, `journalArticle`, `bookSection`, `document` или другой тип из справки скрипта) и обязательное название. Авторы и редакторы идут списками в формате `Фамилия, Имя`. Год, журнал, издательство и печатные страницы бери из документа. Неподтверждённые поля оставляй пустыми. Если название установить не удалось, уточни его у пользователя перед сборкой.
3. Собери RIS.

   ```sh
   ./scripts/make-ris.sh build "<родитель>/zotero-import.json" "<родитель>/zotero-import.ris" --dir "<папка>"
   ```

   Если пользователь задал путь RIS, передай его вторым позиционным аргументом команды `build`. Исправь ошибки валидации до выдачи результата. Перезаписывай существующий RIS с `--force` только по запросу.
4. Сообщи пути к JSON и RIS, перечисли пропущенные реквизиты и предупреждения скрипта. Импорт выполняет пользователь через «Файл → Импортировать… → Из файла». Для сохранения вложений предложи выбрать «Копировать файлы в папку хранилища Zotero».
