# Подготовка файлов перед импортом

Вызывай встроенный инструмент Bionic `shell_command` с полями `command`, `workdir` (абсолютный путь к корню `zotero-ai-integration`) и `timeout_ms` (число в миллисекундах). Для пробного запуска начни с `60000`. Для обработки выбери таймаут с учётом объёма OCR и ограничений инструмента. Если инструмент недоступен, попроси открыть проект с **Allow coding**. Возьми путь к папке из запроса. Если его нельзя определить, уточни. Путь с пробелами передавай в кавычках.

1. Сначала выполни пробный запуск.

   ```sh
   ./scripts/prepare-books.sh "<папка>" --dry-run --copy
   ```

   Передай также запрошенные `--only`, `--lang` или `--out`. Покажи план по файлам. При запросе только на проверку на этом закончи.
2. Если пользователь просит обработать файлы, повтори команду без `--dry-run`. По умолчанию оставляй оригиналы на месте с `--copy`. Если пользователь явно просит перенести готовые файлы, убери `--copy`. Существующие результаты перезаписывай с `--force` только по явному запросу. Если скрипту не хватает зависимости, укажи её пользователю.
3. Для долгого OCR дождись итоговой сводки процесса. Сообщи путь к папке результата (по умолчанию `fixed`), какие файлы скопированы, перемещены, преобразованы или пропущены. Ошибки и предупреждения передай по выводу скрипта. Если проверка показала сдвиг печатных страниц, укажи его.

Для файла, которому скрипт не помог, используй `./scripts/check-pdf.sh "<файл.pdf>"` и объясни вывод. Для подготовки файла импорта используй скил `zotero-import` с путём к фактической папке результата.
