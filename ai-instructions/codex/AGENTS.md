# Работа с библиотекой Zotero

Работай из корня репозитория. Для поиска по библиотеке и чтения источников используй `zotero-library`, для подготовки файлов к загрузке — `prepare-books`, для сборки файла импорта — `zotero-import`.

Перед первым обращением к Zotero в сессии проверь Ollama по инструкции `zotero-library`. Если Ollama недоступен, попроси пользователя его запустить и приостанови работу с библиотекой. Само приложение Zotero для поиска и чтения запускать не нужно.

Используй Zotero только для поиска и чтения. Запись, правка, добавление заметок и тегов, перенос и удаление записей через MCP в этой интеграции не поддерживаются. Файлы для ручного импорта можно готовить локально. Обновляй поисковый индекс только по запросу пользователя.

Структура репозитория описана в корневом `README.md`. Документацию и инструкции редактируй как обычные файлы репозитория.
