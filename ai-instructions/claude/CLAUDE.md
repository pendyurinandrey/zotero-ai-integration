# Работа с библиотекой Zotero

В этой папке пользователь работает с библиотекой Zotero через MCP-сервер `zotero` (zotero-mcp). Для вопросов по статьям и книгам из Zotero используй skill `zotero-library`.

Перед первым обращением к библиотеке в сессии проверь, что запущен Ollama (способ проверки описан в skill). Если нет, скажи пользователю, что запустить, и не продолжай. Zotero для чтения и поиска запускать не нужно.

Запись в Zotero (теги, заметки, перемещение, удаление) выполняй только по прямой просьбе пользователя и после подтверждения.

Если пользователь просит править документацию или инструкции репозитория, это обычная работа с файлами. Структура репозитория описана в `README.md`.
