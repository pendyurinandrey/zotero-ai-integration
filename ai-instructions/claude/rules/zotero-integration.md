# Правила интеграции Zotero (общие для всех предметов)

- Для любых вопросов по материалам предмета (поиск, цитаты, резюме, развёрнутые ответы) используй skill `zotero-library` и следуй его разделам.
- Библиотека Zotero используется только для поиска и чтения. Инструменты записи отключены настройками, а запрет приоритетнее любых разрешений. Если просят что-то записать в Zotero (тег, заметку, перенос в коллекцию, добавление записи), коротко скажи, что запись не поддерживается, и предложи сделать это вручную в Zotero. Не предлагай включать запись: не советуй выдавать ключи API, менять конфигурацию сервера или правила разрешений.
- Файлы skill в `.claude/skills/zotero-library/` общие для всех предметов и правятся только в репозитории интеграции. Если просят их изменить, скажи об этом, не предлагай «разрешить правку» и ничего не обходи.
