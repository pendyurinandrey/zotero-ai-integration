# Подготовка папки к загрузке в Zotero

Аргументы команды: `$ARGUMENTS`. Первое слово без `--` это папка, остальное опции для `prepare-books.sh` (`--only`, `--copy`, `--lang`, `--dry-run`, `--force`, `--out`). Если папка не указана, спроси её у пользователя. Команду запускай из корня репозитория интеграции (`scripts/…`); если сессия открыта в другой папке, используй полный путь к `scripts/prepare-books.sh` репозитория.

Задача: каждый файл папки либо годится к импорту в Zotero как есть, либо его нужно исправить или перевести, чтобы индексатор читал его полный текст. Всю рутину делает скрипт `scripts/prepare-books.sh` (из корня репозитория); твоя часть: запустить, разобрать сводку и решить, что делать с файлами, которым скрипт не помог.

Правила: только то, о чём просит пользователь. Оригиналы не удаляй и не перезаписывай; файл «как есть» переносится в `fixed` (или копируется с `--copy`, если пользователь просит оставить оригинал). Коммитит и пушит пользователь сам. Не меняй файлы репозитория, пока пользователь не разрешил.

## 1. Подготовка

1. Папка: возьми путь из запроса. Если не указана подпапка результата, это `fixed` внутри папки.
2. Проверь зависимости одной командой: `ocrmypdf --version` (`brew install ocrmypdf tesseract-lang`), для DjVu `ddjvu -h` (`brew install djvulibre`). Если чего-то нет, скажи пользователю, что поставить; сам не устанавливай (это системное изменение).
3. Пробный запуск (быстро, ничего не меняет):

```
scripts/prepare-books.sh "<папка>" --dry-run
```

Покажи пользователю план по файлам (что будет с каждым) в одной таблице. Для папок со страницами SVG, DjVu и сканов предупреди, что OCR занимает минуты на книгу.

## 2. Запуск

Запусти без `--dry-run` в фоне (`run_in_background`): OCR книги в 500 страниц это десятки минут. Не опрашивай процесс по кругу: придёт уведомление о завершении. Команда печатает по ходу работы, какие шаги выполнены.

```
scripts/prepare-books.sh "<папка>"
```

Опции: `--only строка` (часть названия, чтобы обработать один файл), `--copy` (копировать, а не переносить файлы «как есть»), `--lang eng` (для англоязычных книг без русского языка), `--force` (перезаписать уже сделанное).

## 3. Сводка и что с ней делать

В конце команда печатает по каждому файлу результат и «сохранность текста до -> после» (1,00 = индексатор читает так же, как просмотрщик; ниже 0,9 тревожно). Разбери итог:

- **готово**: файл в `fixed`, больше ничего.
- **готово, с оговорками** (сохранность 0,85–0,95): обычно таблицы, оглавление и мелкий шрифт. Скажи пользователю причину из замечаний. Если по таблицам нужен точный поиск по числам, предложи сделать `.txt` (раздел «Таблицы» в `docs/setup/06-ocr.md`): индексатор склеивает ячейки таблицы с многоуровневой шапкой.
- **ТРЕБУЕТ ВНИМАНИЯ**: скрипт не справился. Запусти `scripts/check-pdf.sh` на результате и действуй по его «Что сделать»; причины и приёмы описаны в `docs/setup/06-ocr.md` (разделы про скобки, ToUnicode, белые полосы, невидимый текст, повёрнутые страницы). Не повторяй ту же команду без изменений.
- **ошибка** или «пропущено»: назови причину и что сделать.

Что обязательно сказать пользователю в итоге (коротко, таблицей: файл → что сделано → качество):
- какие файлы перенесены как есть, какие исправлены, какие распознаны заново;
- **метаданные**: у большинства сканов нет названия и автора; их нужно вписать в карточку Zotero или записать в файл (`scripts/repair-pdf.sh вход.pdf выход.pdf --title "…" --author "…"`, по титульной странице, а не по догадке: если автор неизвестен, оставь пустым);
- **номера страниц**: сдвиг между печатным номером и номером страницы PDF из замечаний (для ссылок);
- что исходники остались на месте, а результат лежит в `fixed`.

## 4. Особые случаи

- **Папка со страницами SVG**: скрипт сам собирает PDF (порядок по числу в имени файла) и делает OCR с поворотом страниц. Если в имени файлов нет числа или есть пропуски в нумерации (книга неполная), он напишет об этом в сводке: передай это пользователю. Название и автора возьми с титульной страницы, если она есть в книге.
- **DjVu**: цветные иллюстрации сохраняются как чёрная маска (скрипт предупредит); для поиска это не важно.
- **EPUB**: картинки убираются (`--text-only`), номера страниц в PDF свои, а не книжные.
- **Дубли в Zotero** (одна книга двумя записями) в индекс не попадают. Попроси пользователя удалить лишнюю карточку: Zotero через MCP только читается.

## 5. После подготовки

Скажи, что делать дальше (скрипт не делает этого сам):
1. Добавить файлы из `fixed` в Zotero (книге нужна родительская карточка; `.txt` нужна карточка «Документ»).
2. `zotero-mcp update-db --fulltext` (запускай только если пользователь просит).
3. Проверить результат: `scripts/check-text-layer.sh --collection "Название"` и, если нужно, сверить число символов и последнюю страницу в индексе с файлом (в этом чате такая проверка выполнялась для каждой книги; ожидаемое отношение текста в индексе к тексту PDF 1,15–1,18).
