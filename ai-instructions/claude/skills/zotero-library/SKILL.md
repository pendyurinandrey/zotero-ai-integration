# Работа с библиотекой Zotero

Инструменты сервера называются `mcp__zotero__zotero_*`. Поиск по смыслу работает по полным текстам PDF (фрагменты примерно по 1500 символов, русский и английский вперемешку).

## 1. Проверка перед началом (один раз за сессию)

1. Ollama: `curl -s http://127.0.0.1:11434/api/version`. Если нет ответа, попроси пользователя запустить `brew services start ollama`.
2. Zotero: `pgrep -x zotero`. Если процесса нет, попроси запустить Zotero.
3. Если инструменты `mcp__zotero__*` недоступны, сервер не подключён: направь пользователя к `docs/clients/claude-code.md`.
4. Вызови `zotero_get_search_database_status`. Если индекс пуст, скажи об этом.

## 2. Выбор области поиска

Пользователь может ограничить поиск коллекцией («ищи только в коллекции X»). Запомни выбор до конца сессии, пока он его не сменит. Без указания ищи по всей библиотеке.

Сам поиск по смыслу фильтровать по коллекции не умеет, поэтому:

1. Найди коллекцию по названию: `zotero_search_collections` (или `zotero_get_collections`). Если подходит несколько, переспроси пользователя. Если ни одной нет, покажи список коллекций.
2. Получи статьи коллекции: `zotero_get_collection_items`, возьми их `Item Key`.
3. Вызывай `zotero_semantic_search` с параметром `filters`: `{"item_key": {"$in": ["KEY1", "KEY2", ...]}}`.

Подколлекции: не проверено, входят ли они в результат `zotero_get_collection_items`. Если у коллекции есть подколлекции, уточни у пользователя, включать ли их.

## 3. Поиск

- Формулируй запрос по смыслу вопроса пользователя. Модель многоязычная: русский вопрос находит английские статьи. Если результаты слабые, повтори запрос по-английски.
- Бери `limit` 10–15 и сводите фрагменты одной статьи вместе.
- Оценка `Relevance` у этой модели низкая даже у хороших совпадений (около 0,3), поэтому судить о релевантности нужно по тексту фрагмента, а не по числу.
- Если ничего подходящего не нашлось, так и скажи, не подгоняй ответ.

## 4. Формат ответа

Для каждой найденной статьи:
- название, авторы, год, `Item Key`;
- страница (из поля `Location`);
- дословная цитата из `Matched Passage` (не придумывай и не перефразируй как цитату; перевод давай отдельно и помечай как перевод);
- одна строка о том, как это отвечает на вопрос.

Если фрагмента недостаточно для вывода, прочитай нужные страницы: `zotero_read_pdf_pages`.

## 5. Резюме статьи

Для резюме используй `zotero_get_item_fulltext` или `zotero_read_pdf_pages`. Скажи, если текст получен не полностью (книга, лимит страниц) или у статьи нет текстового слоя.

## 6. Ограничения индекса

- Статьи без текстового слоя (сканы) проиндексированы только по метаданным. Если запись найдена только по названию или аннотации, предупреди пользователя.
- Новые статьи появятся в поиске только после обновления индекса: `zotero-mcp update-db --fulltext`. Это долгая операция, запускай только с согласия пользователя.

## 7. Запись в Zotero

Только по прямой просьбе и после подтверждения: что именно будет изменено и в каких записях. Удаление не выполняй. Если запись не авторизована (`zotero_write_capabilities`, `zotero_authorize_local_writes`), объясни пользователю, как дать разрешение в Zotero.
