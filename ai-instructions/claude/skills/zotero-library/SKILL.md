# Работа с библиотекой Zotero

Инструменты сервера называются `mcp__zotero__zotero_*`. Поиск по смыслу работает по полным текстам PDF (фрагменты примерно по 1500 символов, русский и английский вперемешку).

## 1. Проверка перед началом (один раз за сессию)

1. Ollama: `curl -s http://127.0.0.1:11434/api/version`. Если нет ответа, попроси пользователя запустить `brew services start ollama`.
2. Zotero для чтения и поиска запускать не нужно: сервер читает базу напрямую, это проверено и при закрытом Zotero. Не проси пользователя запускать его ради поиска.
3. Если инструменты `mcp__zotero__*` недоступны, сервер не подключён: направь пользователя к `docs/clients/claude-code.md`.
4. Вызови `zotero_get_search_database_status`. Если индекс пуст, скажи об этом.
5. Проверь библиотеку на PDF без текстового слоя, PDF без родительской записи (лежат отдельным вложением и не индексируются) и на статьи, которых нет в индексе: `.claude/skills/zotero-library/scripts/check-text-layer.sh` (если выбрана коллекция, добавь `--collection "Название или ключ"`; путь указан от рабочей папки сессии: скрипты лежат внутри папки skill). Скрипт только читает. Если он нашёл проблемы (код выхода 1), **сообщи о них пользователю до ответа на вопрос**: перечисли статьи и что делать (OCR и вложения без родительской записи: `docs/setup/06-ocr.md`; обновление индекса: `zotero-mcp update-db --fulltext`, с согласия пользователя). Затем отвечай на вопрос по тому, что проиндексировано, и скажи, что указанные статьи в выдачу не попадают. Это предупреждение достаточно сделать один раз за сессию и повторить при смене коллекции. Если сам скрипт завершился ошибкой (код 2, например, коллекция не найдена или неоднозначна), не пропускай проверку молча: исправь вызов (уточни название или возьми ключ из сообщения скрипта) и запусти снова; если не получилось, прямо скажи пользователю, что проверка не выполнена.

## 2. Выбор области поиска

Если в `CLAUDE.md` рабочей папки указана коллекция предмета, ищи в ней и не спрашивай область заново. Правила в `CLAUDE.md` рабочей папки (формат ссылок, режимы, приоритет источников) **имеют приоритет** над форматом по умолчанию из этого skill.

Пользователь может ограничить поиск коллекцией («ищи только в коллекции X»). Запомни выбор до конца сессии, пока он его не сменит. Без указания ищи по всей библиотеке.

**Без коллекции** вызывай MCP-инструмент `zotero_semantic_search` (параметр `query`, `limit` 10–15, без `filters`).

**С коллекцией** MCP-инструмент не подходит: ограничить поиск набором статей можно только вложенным фильтром `{"item_key": {"$in": [...]}}`, а Claude Code не может передать такой фильтр (он превращает JSON-строку в объект, и сервер отклоняет его: схема принимает только строковые значения). Не пробуй передавать `filters` через MCP, это проверено и не работает. Вместо этого запускай скрипт (из корня репозитория, он только читает):

```
.claude/skills/zotero-library/scripts/search-in-collection.sh "запрос" --collection "Название или ключ" --limit 10
```

**Несколько мест из одной записи.** И `zotero_semantic_search`, и `search-in-collection.sh` возвращают **одно лучшее место на запись**, хотя в индексе есть все остальные. Когда пользователю нужно не «в какой статье», а «где именно» (все страницы статьи, все моменты лекции), используй скрипт, который снимает это ограничение:

```
.claude/skills/zotero-library/scripts/search-passages.sh "запрос" [--collection "Название или ключ"] [--item КЛЮЧ] [--limit 10] [--per-item 5]
```

- Без `--collection` ищет по всей библиотеке, с `--item КЛЮЧ` только в одной записи (удобно для вопроса «где в этой статье/расшифровке…»).
- Для каждого места печатает страницу (PDF) и номер фрагмента, а для расшифровок ещё время и спикеров, которые видны в тексте. Соседние фрагменты склеены.
- Если фрагмент начинается с середины реплики, скрипт пишет, чья реплика и в какое время начата в предыдущем фрагменте. Эту подсказку используй для атрибуции.
- `--per-item 1` даёт поведение обычного поиска (одно место на запись). `--limit` это число мест всего.
- Для поиска только по коллекции с одним местом на запись по-прежнему годится `search-in-collection.sh`, но `search-passages.sh --collection ... --per-item 1` делает то же самое.

Скрипт сам находит коллекцию, собирает ключи её статей и выполняет поиск по смыслу только среди них. Вывод в том же формате, что у `zotero_semantic_search` (название, `Item Key`, `Location` со страницей, `Matched Passage`).

- Если название подходит нескольким коллекциям или не найдено, скрипт завершается с кодом 2 и списком вариантов: покажи его пользователю и переспроси.
- Подколлекции по умолчанию не включаются. Если у коллекции есть подколлекции, спроси, включать ли их, и добавь `--subcollections`.
- Запрос на русском и английском: см. следующий раздел.

## 3. Поиск

**Как вызывать скрипт поиска.**
- Вызывай скрипты из `.claude/skills/zotero-library/scripts/` отдельной командой (здесь и ниже путь от рабочей папки сессии): без `for`-циклов, конвейеров (`| grep`, `| cut`, `| head`) и склейки нескольких вызовов через `;`. Только такая команда подходит под заранее разрешённые в `settings.json`; всё остальное вызывает запрос подтверждения у пользователя. Несколько запросов — несколько отдельных вызовов.
- **Не фильтруй вывод.** Цитата (`Matched Passage`) состоит из нескольких строк, а `grep -E "Matched"` оставляет только первую из них. В проверке на реальных данных так сохранялось около 17% текста цитат: остаток выглядит как обрывки («by», «ore or less resistant to change»), и результаты ошибочно кажутся «разрозненными». Читай вывод целиком, он и так ограничен `--limit`.
- Если нужен разделитель между выводами, ставь строку в кавычки: `echo "====="`. В zsh `echo =====` без кавычек падает с ошибкой «not found» (слово на `=` раскрывается как имя команды) и обрывает всю команду.

- Формулируй запрос по смыслу вопроса пользователя. Модель многоязычная: русский вопрос находит английские статьи. Если результаты слабые, повтори запрос по-английски.
- Бери `limit` 10–15 и сводите фрагменты одной статьи вместе.
- Оценка `Relevance` у этой модели низкая даже у хороших совпадений (около 0,3), поэтому судить о релевантности нужно по тексту фрагмента, а не по числу.
- Формулируй запрос как короткое связное предложение или вопрос, а не как перечень ключевых слов через запятую: по смыслу такой запрос ищется лучше.
- Фрагмент может оказаться списком литературы (много «Journal of …, 7, 302–312», годы, DOI): такой результат игнорируй, это не содержание статьи.
- Не делай вывод «результаты разрозненные» и не переходи к чтению полных текстов нескольких статей, пока не убедился, что видел цитаты целиком, а не обрезанными. Чтение полного текста дорогое (около 6 тысяч токенов на статью).
- Если ничего подходящего не нашлось, так и скажи, не подгоняй ответ.

## 4. Формат ответа

Для каждой найденной статьи:
- название, авторы, год, `Item Key`;
- страница (из поля `Location`);
- дословная цитата из `Matched Passage` (не придумывай и не перефразируй как цитату; перевод давай отдельно и помечай как перевод);
- одна строка о том, как это отвечает на вопрос.

Если фрагмента недостаточно для вывода, прочитай нужные страницы: `zotero_read_pdf_pages` (аргументы `item_key`, `start_page`, необязательно `end_page`, нумерация с 1).

Если `zotero_read_pdf_pages` отвечает «No text layer on this page — it is a scanned image», но поиск по этой статье фрагменты возвращал, значит это скан с готовым текстовым слоем (OCR под картинкой страницы), и этот инструмент его не видит. В таком случае возьми текст через `zotero_get_item_fulltext` (аргумент `item_key`; номера страниц бери из поля `Location` фрагментов поиска). Не заключай по ответу «No text layer», что текста нет вообще, и не говори пользователю, что статья не читается, пока не проверишь `zotero_get_item_fulltext`.

### Расшифровки лекций и семинаров

В расшифровках каждая реплика записана как `[ЧЧ:ММ:СС] Спикер: текст`. Спикер и время хранятся только внутри текста, отдельных полей в индексе нет. В ответе давай: название записи (файл), время (`[ЧЧ:ММ:СС]` начала реплики, а не точная минута фразы), спикера и цитату.
- Приписывай фразу спикеру только по **полному заголовку реплики** (`[время] Спикер:`). Начало фрагмента до первого таймкода продолжает реплику из предыдущего фрагмента: бери автора и время из подсказки скрипта, а если её нет, так и скажи.
- Метки «Спикер N» действуют только внутри одной записи («Спикер 5» в разных файлах это разные люди). «Преподаватель» и подобные подписи осмысленны сами по себе. **В расшифровках лекций спикеров обычно нет** (один говорящий, реплика записана как `[время] текст`): в этом случае автор — лектор, и указывать нужно только время. Двоеточие внутри фразы («А психологи сказали: …») не метка спикера.
- Для вопроса «где обсуждали X» запускай `search-passages.sh` (не обычный поиск), чтобы увидеть все моменты, а не один.

## 5. Развёрнутый ответ с источниками

Так отвечай на запросы вида «подготовь развёрнутый ответ / расширенную версию … со ссылками на источники» по коллекции с лекциями, семинарами и учебниками. Один общий запрос (например, «Методы психологических исследований») находит в основном учебники, а лекции и семинары остаются в тени, поэтому тему нужно **разбить**.

1. **Область.** Возьми коллекцию, названную пользователем (или выбранную ранее). Сделай проверку из раздела 1.
2. **План подтем.** Составь 5–10 подтем: определение и место в науке, классификация, каждый отдельный вид или метод, достоинства и ограничения, примеры, критика. Если нужна опора на структуру учебника, найди его оглавление или введение запросом по главе.
3. **Обзор по подтемам.** На каждую подтему один отдельный вызов, без циклов и конвейеров:
   `.claude/skills/zotero-library/scripts/search-passages.sh "связное предложение по подтеме" --collection "Название" --limit 8 --per-item 2 --max-chars 600`
   Эти параметры нужны, чтобы обзор был дешёвым: проверено на реальной коллекции, 8 таких вызовов дают около 27 тысяч токенов (с `--limit 12 --per-item 3 --max-chars 700` почти 42 тысячи). Не повторяй одинаковые запросы. Запрос формулируй так, как это сказано в учебниках и лекциях, а не копируй формулировку пользователя целиком.
4. **Углубление.** Для 2–4 лучших мест каждой подтемы прочитай полный текст: тот же запрос с `--item КЛЮЧ` и без `--max-chars`, либо страницы PDF (`zotero_read_pdf_pages`). Не читай полные тексты книг и записей целиком.
5. **Ответ.** Структурируй по подтемам (заголовки), каждая мысль опирается на найденное место. Различай источники по природе: **учебник** (определения, классификации, терминология), **лекция/семинар** (акценты преподавателя, примеры, обсуждение со студентами). Не приписывай вывод лектора учебнику и наоборот. Если по подтеме ничего не нашлось, прямо напиши «в материалах коллекции не найдено», не достраивай от себя.

**Ссылки на источники.** В тексте ставь номера сносок `[1]`, `[2]`, в конце дай нумерованный список источников:
- лекция или семинар: «Лекция 09.09.2026, 00:56:04, Преподаватель» (время начала реплики; для нескольких реплик диапазон `00:56:04–00:58:17`); название записи как в Zotero;
- учебник или статья со страницами: «Нуркова В. В., Березанская Н. Б. Общая психология, с. 38–39», «Ждан А. Н. История психологии, с. 129»; страницы бери из строки места («стр. …»);
- если страницы нет, укажи запись и номер фрагмента.
В списке добавь `Item Key` записи. Дословные цитаты ставь в кавычки и делай короткими; остальное пересказывай. Речь в расшифровках разговорная, с оговорками и ошибками распознавания: пересказывай литературным языком и помечай, что это по лекции.

## 6. Резюме статьи

1. Метаданные: `zotero_get_item_metadata` (авторы, год, название; аннотацию можно использовать как ориентир, но не как замену тексту).
2. Текст: `zotero_get_item_fulltext` отдаёт **только первые 10 страниц** (около 6 тысяч токенов), а не весь документ. Если в ответе заголовок «Full Text (pages 1-10 of N — TRUNCATED)», документ длиннее: дочитывай `zotero_read_pdf_pages` порциями (`start_page=11`, `end_page=…`, по 15–20 страниц за вызов, не больше 50; 30 страниц это около 13 тысяч токенов) и строй резюме по частям: сначала краткие выводы по каждой порции, затем общее резюме.
3. **Расшифровки (`.txt`) страниц не имеют**: `zotero_get_item_fulltext` отдаёт их **целиком и без усечения**. Лекция на 3 часа это около 140 тысяч символов, то есть около 47 тысяч токенов. Перед чтением полной расшифровки предупреди пользователя о стоимости. Для резюме лекции предпочти разбивку по темам: несколько вызовов `.claude/skills/zotero-library/scripts/search-passages.sh "тема" --item КЛЮЧ --per-item 6 --max-chars 600` (в начале спроси или предложи основные темы), а целиком читай только по согласию пользователя.
4. Книги и большие документы (больше 50 страниц): не читай подряд целиком. Посмотри оглавление (`zotero_get_pdf_outline`) и уточни у пользователя, какие главы нужны. Для вопросов вроде «в чём главный вывод» используй `.claude/skills/zotero-library/scripts/search-passages.sh "вопрос" --item КЛЮЧ --per-item 8`.
5. Скан с готовым OCR-слоем: `zotero_read_pdf_pages` может ответить «No text layer on this page», а `zotero_get_item_fulltext` отдаст только первые 10 страниц. Для остального текста используй `.claude/skills/zotero-library/scripts/search-passages.sh ... --item КЛЮЧ` по темам либо предложи пользователю поднять `semantic_search.extraction.fulltext_display_max_pages` в конфиге zotero-mcp.
6. В самом резюме всегда пиши, какие страницы прочитаны («стр. 1–30 из 41»), если прочитан не весь документ. Структура: цель, метод, результаты, выводы, ограничения; ссылки на страницы; не добавляй того, чего нет в прочитанном тексте.

## 7. Ограничения индекса

- Статьи без текстового слоя (сканы) проиндексированы только по метаданным. Если запись найдена только по названию или аннотации, предупреди пользователя. Список таких статей даёт `.claude/skills/zotero-library/scripts/check-text-layer.sh` (шаг 5 проверки в начале).
- Файлы, лежащие в Zotero отдельным вложением без родительской записи (расшифровки, учебники в `.txt`), **не индексируются**: у каждого файла должна быть запись-карточка (например, тип «Документ»). О таких файлах предупредит `.claude/skills/zotero-library/scripts/check-text-layer.sh`, скажи пользователю создать карточку и перетащить в неё файл.
- Новые статьи появятся в поиске только после обновления индекса: `zotero-mcp update-db --fulltext`. Это долгая операция, запускай только с согласия пользователя.

## 8. Только чтение

Не изменяй библиотеку: не вызывай инструменты добавления, правки, тегов, заметок, переноса и удаления. Если пользователь просит такое, скажи, что запись в Zotero пока не поддерживается.
