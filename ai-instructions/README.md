# Инструкции для нейросетей

Здесь лежат файлы, которые читает сама нейросеть: как пользоваться библиотекой Zotero через MCP-сервер.

- `common/` — правила, общие для всех нейросетей (описание на человеческом языке; клиентские файлы ссылаются на них).
- `<нейросеть>/` — файлы в формате, который понимает конкретная нейросеть. Состав файлов у каждой свой.

Инструкции по установке этих файлов у клиента лежат в `docs/clients/`.
