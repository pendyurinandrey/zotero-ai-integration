# 3. Ollama и модель bge-m3

`bge-m3` — локальная многоязычная модель эмбеддингов (русский и английский). Она превращает текст в векторы для поиска по смыслу и не генерирует ответы. Все данные остаются на компьютере.

## Установка

```bash
brew install ollama
brew services start ollama   # запускать Ollama автоматически (рекомендуется)
ollama pull bge-m3           # ~1,2 ГБ
```

Вместо `brew services start ollama` можно запускать `ollama serve` вручную в отдельном терминале, но тогда сервер остановится вместе с терминалом.

## Проверка

```bash
ollama list
```

Должна быть строка `bge-m3:latest`.

```bash
curl -s http://127.0.0.1:11434/api/embed -d '{"model":"bge-m3","input":["Привет, мир","hello world"]}'
```

В ответе должны быть два вектора длиной 1024.

Проверка, что русский и английский сопоставляются: вопрос по-русски и тот же вопрос по-английски дают близкие векторы (косинусное сходство ≈ 0,85), а несвязанный текст — далёкие (≈ 0,26). Измерено на нашей установке, см. [versions.md](../versions.md).

## Требования

- Около 1,2 ГБ на диске под модель, 1–2 ГБ ОЗУ при работе.
- GPU не нужен, на Apple Silicon работает на процессоре и ускорителе.
- Интернет нужен только для скачивания модели.
