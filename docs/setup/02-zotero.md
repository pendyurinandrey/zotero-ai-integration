# 2. Zotero и локальный API

Нужен Zotero 10 (в нём локальный API умеет и читать, и писать). Сервер ходит в библиотеку через локальный API, облако и API-ключ не нужны.

## Включить доступ для внешних приложений

В настройках Zotero включите опцию **«Allow other applications on this computer to communicate with Zotero»** (раздел Advanced; точное расположение уточнить на вашей версии). После включения Zotero покажет в настройках адрес локального сервера. Запомните его: порт может отличаться на разных компьютерах, поэтому в этой документации адрес обозначен как `<ZOTERO_API_URL>` (например, он заканчивается на `/api`).

Zotero должен быть запущен каждый раз, когда вы работаете с библиотекой через ИИ.

## Проверка

```bash
curl -s -H "Zotero-API-Version: 3" "<ZOTERO_API_URL>/users/0/items?limit=2&format=json"
```

Подставьте вместо `<ZOTERO_API_URL>` адрес из настроек Zotero. Ожидаемый результат: JSON со списком записей вашей библиотеки. Ответ `403 Forbidden` означает, что опция не включена.

## Запись

Операции записи в Zotero 10 требуют разрешения: при первой попытке записи Zotero покажет запрос (разово или постоянно). Если вам нужен только поиск, разрешение на запись не давайте.
