# 2. Zotero

Нужен Zotero 10. Поиск и чтение библиотеки **не требуют** никаких настроек Zotero: сервер читает базу `zotero.sqlite` напрямую (точнее, её копию вместе с журналом `-wal`: Zotero может быть и запущен, и закрыт). Облако Zotero и API-ключ не нужны.

Проверено 2026-10-03 на Zotero 10.0.5: при **выключенной** опции «Allow other applications on this computer to communicate with Zotero» и при **закрытом Zotero** все читающие инструменты сервера работают: поиск по смыслу, обычный поиск, список коллекций и их статей, метаданные, полный текст, чтение страниц PDF, вложения, теги, аннотации, обновление индекса. Скрипты репозитория тоже работают.

Поэтому эту опцию включать не нужно.
