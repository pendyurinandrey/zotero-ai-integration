# 4. MCP-сервер zotero-mcp

Единая точка входа в Zotero для нейросетей: [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) (лицензия MIT). Он читает библиотеку Zotero, строит индекс для поиска по смыслу (через Ollama и `bge-m3`) и отдаёт инструменты нейросети по протоколу MCP.

## Установка

Ставим через `uv tool`, в собственное окружение, с явно заданным Python (не 3.14):

```bash
uv tool install --python 3.13 "zotero-mcp-server[semantic,pdf]"
```

Скачивается около 1,2 ГБ (вместе с `torch`). Исполняемые файлы кладутся в `~/.local/bin`. Если команда `zotero-mcp` не находится, добавьте эту папку в `PATH`:

```bash
uv tool update-shell
```

(команда правит конфиг вашего шелла; после неё откройте новый терминал).

## Установка форка (нужна настройка `snippet_width`)

Оригинальный `zotero-mcp-server` настройку `snippet_width` не знает. Мы используем форк с минимальным патчем: [pendyurinandrey/zotero-mcp](https://github.com/pendyurinandrey/zotero-mcp), тег `v0.13.1-snippet-width` (ветка `configurable-snippet-width`, база: оригинал 0.13.1). Ссылаемся на тег, а не на ветку: тег не сдвигается, если ветка меняется по замечаниям ревьюеров. Правка: ширина цитаты берётся из необязательного ключа `semantic_search.snippet_width`; если ключ не задан, поведение оригинала не меняется (320 символов). Заодно убрана лишняя вторая обрезка до 400 символов: она никогда не срабатывала, но обрезала бы увеличенную ширину. Добавлены тесты, проходит весь набор тестов (3653).

Установка вместо команды выше:

```bash
uv tool install --python 3.13 "zotero-mcp-server[semantic,pdf] @ git+https://github.com/pendyurinandrey/zotero-mcp.git@v0.13.1-snippet-width"
```

Проверено 2026-10-03: установка по этой ссылке в чистое окружение проходит, версия `Zotero MCP v0.13.1`, патч на месте. Предложение в оригинальный репозиторий: [54yyyu/zotero-mcp#626](https://github.com/54yyyu/zotero-mcp/pull/626). Если его примут и выпустят релиз, форк будет не нужен: тогда достаточно команды выше без суффикса `@ git+...` (`uv tool install --python 3.13 "zotero-mcp-server[semantic,pdf]"`) и инструкцию стоит обновить.

Если у вас уже стоит оригинальный `zotero-mcp-server`, поставьте форк поверх: добавьте в команду `--reinstall`.

## Проверка

```bash
zotero-mcp version
```

Должно вывести версию (мы проверяли на 0.13.1).

## Конфигурация поиска по смыслу

Файл `~/.config/zotero-mcp/config.json`:

```json
{
  "semantic_search": {
    "snippet_width": 1500,
    "embedding_model": "ollama",
    "embedding_config": {
      "model_name": "bge-m3",
      "timeout": 600,
      "request_batch_size": 16
    },
    "include_fulltext": true,
    "extraction": {
      "pdf_max_pages": 1000
    },
    "chunking": {
      "enabled": true,
      "chunk_size": 1500,
      "overlap": 200,
      "max_chunks_per_item": 800
    }
  }
}
```

Зачем каждая настройка:

- `embedding_model: ollama` и `model_name: bge-m3` — многоязычные эмбеддинги через локальный Ollama (адрес по умолчанию `http://localhost:11434`).
- `chunking.enabled: true` — **обязательно**. Без него каждая статья превращается в один вектор, и поиск находит статью, но не место в ней, а длинные тексты обрезаются. С разбиением на фрагменты поиск возвращает конкретные отрывки для цитат.
- `chunk_size` и `overlap` — размер фрагмента и перекрытие, в символах.
- `max_chunks_per_item: 800` — по умолчанию 20 фрагментов на документ (около 30 тысяч символов, то есть примерно 10 страниц), для книг этого мало.
- `snippet_width: 1500` — **наше значение, не умолчание**: длина цитаты, которую сервер отдаёт нейросети вместе с каждой найденной статьёй. В оригинальном zotero-mcp 0.13.1 этой настройки нет: цитата всегда окно в 320 символов, подобранное по совпадению слов запроса; при русском вопросе к английским статьям оно обычно берётся с начала фрагмента, и нужное место теряется. Мы ставим 1500 (размер фрагмента), чтобы получать фрагменты целиком. В форке, если ключ не задан, поведение такое же, как в оригинале (320 символов). Настройка есть только в форке (см. ниже).
- `pdf_max_pages: 1000` — по умолчанию читается только часть страниц PDF, для книг нужно больше.

Папку конфига стоит закрыть от других пользователей:

```bash
chmod 700 ~/.config/zotero-mcp
```

Проверка, что конфиг подхвачен:

```bash
zotero-mcp db-status
```

В выводе должно быть `Embedding model: ollama` и `Passage chunking: enabled`.

## Как сервер подключается к Zotero

Режим `ZOTERO_LOCAL=true` (используется в конфиге MCP-клиента) читает библиотеку локально. Для записи в Zotero 10 нужна отдельная авторизация (`zotero-mcp authorize-local`). Если вам нужен только поиск, не выполняйте её.
