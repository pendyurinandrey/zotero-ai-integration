# 4. MCP-сервер zotero-mcp

Единая точка входа в Zotero для нейросетей: [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) (лицензия MIT). Он читает библиотеку Zotero, строит индекс для поиска по смыслу (через Ollama и `bge-m3`) и отдаёт инструменты нейросети по протоколу MCP.

## Установка

Ставим через `uv tool`, в собственное окружение, с явно заданным Python (не 3.14). Мы используем **форк** оригинала с одной дополнительной настройкой (`snippet_width`, подробнее ниже), поэтому команда ставит его, а не пакет с PyPI:

```bash
uv tool install --python 3.13 "zotero-mcp-server[semantic,pdf] @ git+https://github.com/pendyurinandrey/zotero-mcp.git@v0.13.1-snippet-width"
```

Скачивается около 1,2 ГБ (вместе с `torch`). Исполняемые файлы кладутся в `~/.local/bin`. Если команда `zotero-mcp` не находится, добавьте эту папку в `PATH`:

```bash
uv tool update-shell
```

(команда правит конфиг вашего шелла; после неё откройте новый терминал).

### О форке

Оригинальный [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) (лицензия MIT) настройку `snippet_width` не знает, а конфиг ниже она молча игнорирует. Форк [pendyurinandrey/zotero-mcp](https://github.com/pendyurinandrey/zotero-mcp) отличается от оригинала 0.13.1 одним коммитом: ширина цитаты берётся из необязательного ключа `semantic_search.snippet_width`; если ключ не задан, поведение оригинала не меняется (320 символов). Заодно убрана лишняя вторая обрезка до 400 символов: она никогда не срабатывала, но обрезала бы увеличенную ширину. Добавлены тесты, проходит весь набор тестов (3653). Ссылаемся на тег, а не на ветку: тег не сдвигается, если ветка меняется по замечаниям ревьюеров.

Проверено 2026-10-03: установка по этой ссылке в чистое окружение проходит, версия `Zotero MCP v0.13.1`, патч на месте. Предложение в оригинальный репозиторий: [54yyyu/zotero-mcp#626](https://github.com/54yyyu/zotero-mcp/pull/626).

- Если у вас уже стоит оригинальный `zotero-mcp-server`, добавьте в команду `--reinstall`.
- Если изменение примут и выпустят релиз, форк будет не нужен: достаточно `uv tool install --python 3.13 "zotero-mcp-server[semantic,pdf]"`, а инструкцию стоит обновить.

## Проверка

```bash
zotero-mcp version
```

Должно вывести версию (мы проверяли на 0.13.1).

## Конфигурация поиска по смыслу

Создайте каталог и закройте его от других пользователей:

```bash
mkdir -p ~/.config/zotero-mcp
chmod 700 ~/.config/zotero-mcp
```

Затем создайте в нём файл `~/.config/zotero-mcp/config.json` (любым редактором или вставьте блок JSON ниже в команду `cat > ~/.config/zotero-mcp/config.json`) со следующим содержимым:

```json
{
  "semantic_search": {
    "snippet_width": 1500,
    "embedding_model": "ollama",
    "embedding_config": {
      "model_name": "bge-m3",
      "timeout": 600,
      "request_batch_size": 16
    },
    "include_fulltext": true,
    "extraction": {
      "pdf_max_pages": 1000
    },
    "chunking": {
      "enabled": true,
      "chunk_size": 1500,
      "overlap": 200,
      "max_chunks_per_item": 3000
    }
  }
}
```

Зачем каждая настройка:

- `embedding_model: ollama` и `model_name: bge-m3` — многоязычные эмбеддинги через локальный Ollama (адрес по умолчанию `http://localhost:11434`).
- `chunking.enabled: true` — **обязательно**. Без него каждая статья превращается в один вектор, и поиск находит статью, но не место в ней, а длинные тексты обрезаются. С разбиением на фрагменты поиск возвращает конкретные отрывки для цитат.
- `chunk_size` и `overlap` — размер фрагмента и перекрытие, в символах.
- `max_chunks_per_item: 3000` — по умолчанию 20 фрагментов на документ (около 30 тысяч символов, то есть примерно 10 страниц), для книг этого мало. Учебник на 600 страниц это около 1000–1400 фрагментов, `.txt` на 1,5 МБ около 1400 (проверено).
- `snippet_width: 1500` — **наше значение, не умолчание**: длина цитаты, которую сервер отдаёт нейросети вместе с каждой найденной статьёй. В оригинальном zotero-mcp 0.13.1 этой настройки нет: цитата всегда окно в 320 символов, подобранное по совпадению слов запроса; при русском вопросе к английским статьям оно обычно берётся с начала фрагмента, и нужное место теряется. Мы ставим 1500 (размер фрагмента), чтобы получать фрагменты целиком. В форке, если ключ не задан, поведение такое же, как в оригинале (320 символов). Настройка есть только в форке (см. ниже).
- `pdf_max_pages: 1000` — по умолчанию читается только часть страниц PDF, для книг нужно больше.

Проверка, что конфиг подхвачен:

```bash
zotero-mcp db-status
```

В выводе должно быть `Embedding model: ollama` и `Passage chunking: enabled`.

## Как сервер подключается к Zotero

Режим `ZOTERO_LOCAL=true` (используется в конфиге MCP-клиента) читает библиотеку локально напрямую из `zotero.sqlite` (из копии вместе с журналом `-wal`). Для чтения локальный API Zotero и его адрес не нужны: проверено на Zotero 10.0.5 при выключенном API, см. [шаг 2](02-zotero.md).
