# Подключение Codex

Выполните [шаги 1–5 общей настройки](../../README.md#с-чего-начать) на macOS. Откройте в Codex корень репозитория интеграции. Инструкции и скилы для клиента лежат в [`ai-instructions/codex/`](../../ai-instructions/codex/README.md).

## 1. Подключите скилы

Выполните из корня репозитория. Команды сохраняют уже существующие файлы и ссылки.

```sh
mkdir -p .agents/skills
for skill in zotero-library prepare-books zotero-import; do
  link=".agents/skills/$skill"
  if [ ! -e "$link" ] && [ ! -L "$link" ]; then
    ln -s "../../ai-instructions/codex/skills/$skill" "$link"
  fi
done
```

В новой сессии в этой папке проверьте список скилов. В CLI можно ввести `$` и выбрать скил по имени. Корневой `AGENTS.md` также указывает на файлы с инструкциями для прямого чтения. [Документация Codex о скилах](https://developers.openai.com/codex/skills).

## 2. Подключите Zotero MCP в режиме чтения

1. Узнайте абсолютный путь к серверу командой `command -v zotero-mcp`. После установки через `uv` это обычно `/Users/<имя>/.local/bin/zotero-mcp`.
2. Если `.codex/config.toml` отсутствует, создайте его из [образца](../../ai-instructions/codex/mcp.toml.example).

   ```sh
   mkdir -p .codex
   if [ ! -e .codex/config.toml ] && [ ! -L .codex/config.toml ]; then
     cp ai-instructions/codex/mcp.toml.example .codex/config.toml
   fi
   ```

   Если конфигурация уже есть, добавьте или обновите в ней секции `[mcp_servers.zotero]` и `[mcp_servers.zotero.env]` по образцу. Сохраните настройки других серверов.
3. В поле `command` укажите абсолютный путь из первого шага. Сохраните `ZOTERO_LOCAL = "true"` и `enabled_tools`. Этот список ограничивает доступ Codex читающими инструментами Zotero.
4. Откройте новую сессию Codex из корня репозитория. Проектная конфигурация MCP применяется в доверенной папке. Проверьте сервер `zotero` через `/mcp` в сессии или `codex mcp list` в терминале из корня. [Документация Codex о MCP](https://developers.openai.com/codex/mcp).

Храните конфигурацию с абсолютным путём к серверу локально на своём Mac.

## 3. Проверьте работу

Запустите Ollama командой `brew services start ollama`. Для чтения и поиска приложение Zotero может быть закрыто.

| Запрос в Codex | Что проверить |
|---|---|
| «В каких источниках Zotero обсуждается X? Приведи цитату со страницей». | Codex проверяет Ollama и индекс, ищет по библиотеке и указывает название источника, страницу и `Item Key`. |
| «Ищи только в коллекции X. Покажи несколько мест, где обсуждается Y». | Поиск ограничен выбранной коллекцией. Для расшифровок Codex приводит таймкоды начала реплик. |
| «Проверь папку … перед импортом, только пробный запуск». | Codex показывает план обработки и сохранения файлов. |
| «Подготовь RIS для папки …/fixed». | Codex собирает JSON с реквизитами и файл RIS для ручного импорта в Zotero. |

Если Codex видит файлы проекта, а `/mcp` не показывает сервер, проверьте, что сессия открыта локально на Mac и использует проектную конфигурацию. Если Ollama отвечает, начните диагностику с [раздела об индексировании](../setup/05-indexing.md) и [типичных ошибок](../troubleshooting.md).
