# Подключение Claude Code

Claude Code работает с Zotero через MCP-сервер `zotero` (шаги 1–5 общей части должны быть выполнены). Работать с библиотекой нужно из папки этого репозитория: тогда Claude автоматически подхватывает инструкции из `ai-instructions/claude/`.

## 1. Подключить MCP-сервер

Выполните в папке репозитория (область `local`: сервер подключится только для этой папки):

```bash
cd <путь к этому репозиторию>
claude mcp add zotero -e ZOTERO_LOCAL=true -- ~/.local/bin/zotero-mcp
```

Если вы пользуетесь приложением Claude (вкладка Code), отдельной команды `claude` в терминале может не быть. Тогда используйте исполняемый файл из приложения:

```bash
"$(find ~/Library/Application\ Support/Claude/claude-code -path '*MacOS/claude' -type f | head -1)" mcp add zotero -e ZOTERO_LOCAL=true -- ~/.local/bin/zotero-mcp
```

Проверка:

```bash
claude mcp list
```

Должно быть `zotero ... ✔ Connected`. Сервер запускать вручную не нужно: Claude Code стартует его сам. Вручную должен быть запущен Ollama.

Убрать подключение: `claude mcp remove zotero`.

## 2. Что лежит в репозитории для Claude

Всё содержимое находится в `ai-instructions/claude/`, а в корне и в `.claude/` лежат только тонкие ссылки на него:

| Что Claude Code ищет | Что там | Куда ведёт |
|---|---|---|
| `CLAUDE.md` в корне | одна строка `@ai-instructions/claude/CLAUDE.md` | общие правила |
| `.claude/skills` | символическая ссылка | `ai-instructions/claude/skills/` (skill `zotero-library`) |
| `.claude/settings.json` | символическая ссылка | `ai-instructions/claude/settings.json` (разрешения) |

Устанавливать эти файлы отдельно не нужно, они работают после клонирования репозитория.

## 3. Разрешения

В `ai-instructions/claude/settings.json` заранее разрешены только **читающие** инструменты (поиск, чтение, список коллекций), поэтому Claude не спрашивает подтверждения на каждый поиск. Библиотека используется только для поиска и чтения: инструкции запрещают Claude изменять Zotero.

Claude Code применяет разрешения из `.claude/settings.json` только после того, как вы подтвердите доверие к папке: при первом запуске в ней появится диалог «Do you trust this folder» (в приложении аналогичное окно). Согласитесь, иначе разрешения будут проигнорированы и Claude будет спрашивать подтверждение на каждый вызов поиска.

## 4. Как пользоваться

1. Запустите Ollama. Zotero запускать не обязательно: сервер читает файлы библиотеки напрямую.
2. Откройте Claude Code в папке репозитория.
3. Задайте вопрос по библиотеке. Чтобы искать только в одной коллекции, скажите: «Работаем с коллекцией X» или «Ищи только в коллекции X».

Claude проверит Ollama (и текстовый слой PDF, см. [OCR](../setup/06-ocr.md)), затем выполнит поиск. Поиск по всей библиотеке идёт через MCP-инструмент, поиск внутри коллекции — через скрипт `scripts/search-in-collection.sh`: MCP не позволяет передать нужный фильтр. Ответ содержит названия статей, страницы и дословные цитаты. Подробности — в `ai-instructions/claude/skills/zotero-library/SKILL.md`.
